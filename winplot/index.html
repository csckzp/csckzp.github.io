Winplot for Mac

A fast, native macOS port of the classic mathematical graphing program. Designed for Apple Silicon with high-resolution Retina rendering.

Download winplot.dmg Apple Silicon (M-series) • macOS 12 Monterey or later • Preview

Overview & Capabilities

Native Performance

Built with Swift and AppKit directly for Apple Silicon for instant startup, smooth window resizing, and energy efficiency.

2D & 3D Graphing

Plot explicit functions, implicit equations, polar curves, parametric equations, and interactive 3D surfaces.

Legacy Compatibility

Preserves the proven mathematical engine and full support for opening classic .wp2 and .wp3 Winplot documents.

Analysis & Calculus

Numerical integration, root finding, extrema detection, tangent lines, derivatives, and customizable data tables.

Installation

1
Download the winplot.dmg disk image using the link above.
2
Double-click the .dmg file to open it, then drag Winplot.app into your Applications folder.
3
Launch Winplot from Applications or Spotlight.
Testing note: As a preview test build, if macOS asks to verify the developer on first launch, Control-click (or right-click) Winplot.app and select Open, then confirm by clicking Open in the dialog.
