K-Nearest Neighbors: From Distance to Prediction

Move the test case around the plot. The highlighted training cases are its K nearest neighbors. Their majority label becomes the prediction.

Mouse: move to preview, click to freeze. Touch: drag to place the test case. Keyboard: focus the plot, then use the arrow keys (hold Shift for bigger steps).

The prediction map repeats the same neighbor vote at many locations. The edge where the predicted color changes is the decision boundary.

This demonstration uses two features so that we can see the data. KNN can use more than two features even when the resulting comparisons cannot be drawn on a screen.

    Teaching Options
    What to notice
    • Moving the test case changes which training cases are closest.
    • Changing K changes how many nearby cases influence the prediction.
    • A small K produces a very local decision.
    • A larger K uses a broader neighborhood.
    • Nearby cases provide evidence, not a guarantee.
    • The two-dimensional plot is for human visualization; KNN can calculate distance using more features than we can draw.
